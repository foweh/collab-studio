## 4. 失败项详情

### F-1:Flask 场景检测子进程无法启动

- **现象**:启动日志 `[Flask] ModuleNotFoundError: No module named 'imagehash'`,`Flask 进程退出 (code=1)`
- **原因**:测试环境 Python 缺 `imagehash` 包(scenedetect-server/server.py 第 5 行硬 import)
- **复现**:任意环境缺该依赖启动即复现
- **分类**:环境依赖缺失,**非代码 bug**。服务端已正确降级(代理返回 502 不崩溃)
- **修复建议**:`pip install imagehash`(或按 README 安装 `flask opencv-python imagehash Pillow`)

### F-2:SSL 证书缺失警告(非故障)

- **现象**:stderr 出现 `[SSL] 证书未找到,仅启动 HTTP`
- **原因**:测试时临时移走了 ssl/ 目录以避开 443 端口占用(本机环境)
- **分类**:预期降级行为,非 bug。部署时用 `node scripts/gen-ssl-certs.js` 生成证书即可

### 观察项(非失败,记录备查)

| 观察 | 说明 |
|------|------|
| operation-log.json 偶发 rename ENOENT | 高并发写操作日志时,`[持久化] 重命名失败` 偶现;数据最终仍落盘,不影响功能。可能与 persist.js 的 setImmediate 写队列与 logger 双路径相关,建议后续关注 |
